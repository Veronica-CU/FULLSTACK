# Experiment 3 - Responsive React UI + Design System + PWA

This project demonstrates:

- Responsive UI with Material UI Grid/Flexbox
- Reusable design system (tokens + theme + reusable components)
- UI interaction testing with Vitest + Testing Library
- PWA deployment support with offline caching (Vite PWA plugin)

## Run locally

```bash
npm install
npm run dev
```

## Run tests

```bash
npm run test
```

## Build for deployment

```bash
npm run build
```
